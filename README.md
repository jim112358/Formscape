# Formscape

用数学表达式探索二维曲线和三维曲面。浏览器本地运行，无外部依赖。

## 在线使用

[打开 Formscape](https://jim112358.github.io/Formscape/)，无需安装。

GitHub Pages 使用 `.github/workflows/pages.yml` 自动部署；推送到 main 时先运行测试，再发布静态文件。仓库 Settings → Pages 的 Source 应设为 GitHub Actions。

## 运行

需要 Node.js 20 或更新版本。

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。运行 `npm test` 检查数学解析器。

没有 npm 时，可直接运行 `node server.js`，并用 `node --test` 检查。

本地服务支持自动刷新：保存 HTML、CSS 或应用 JS 文件后，浏览器会自动重新加载，已保存的公式和范围会恢复。首次启用需重启服务并手动刷新一次。修改 `server.js` 后仍需重启服务。此功能仅由本地服务注入，不影响 GitHub Pages。

## 当前原型

- 二维函数、二维参数曲线、三维函数曲面、空间曲线、参数曲面
- 坐标轴、网格、等比例坐标、缩放、平移或旋转
- 共享参数 a，公式错误提示，项目 JSON 导入导出，本地自动保存，PNG 导出
- 支持 `sin cos tan asin acos atan sqrt abs ln log exp floor ceil`、`pi` / `π`、`e`、幂和隐式乘法

公式只填写等号右侧；角度使用弧度。参数曲线使用 t，参数曲面使用 u、v。

## 已知限制

这是初始原型。曲面使用 Canvas 投影与规则网格，尚无 GPU 深度缓冲；复杂曲面遮挡可能不准确。曲线通过采样距离启发式断开，不保证识别所有不连续点。当前仅提供共享参数 a，尚未实现任意参数识别、逐图范围、数学排版、后台采样和视角持久化。输入错误时当前图形隐藏。

## 分段函数

输入 `piecewise(x < 0, x^2, sin(x))`：负半轴绘制平方，其他位置绘制正弦。
多段示例：`piecewise(x < -1, -1, x <= 1, x, 1)`。
按顺序选择第一个成立的条件；末尾可选默认表达式，没有匹配且无默认值时不绘制。
条件支持 `< <= > >= == !=`，以及 `&&`（且）、`||`（或），不支持数学连写 `0<x<1`，应写 `x>0 && x<1`。
所有绘图类型均支持；参数曲线使用 t，曲面可使用 x、y 或 u、v。不同分段不直接连线，采样可能使边界存在细小间隙。

## 坐标范围设置

X、Y、Z 可以独立设置最小值与最大值，支持 `pi` 等表达式。二维函数按 X 范围计算，Y 默认根据结果自动适配；三维函数曲面按 X、Y 范围计算，Z 默认自动适配。请取消 Y 的“自动”来指定三维函数的 Y 自变量范围。自变量勾选自动时使用默认范围 `[-6.28,6.28]`。

参数曲线使用独立的 t 范围，参数曲面使用独立的 u、v 范围。将 X、Y、Z 勾选自动即可适配参数图形结果。自动范围跳过非有限值，并通过四分位距过滤极端离群值，因此部分极端结果可能不显示。各坐标轴独立缩放，图形比例可能发生变化。范围设置随项目自动保存并支持旧项目迁移。
